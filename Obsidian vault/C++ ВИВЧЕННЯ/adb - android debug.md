adb is an android debug tools that work through connecting pc through usb to an android phone
adb has to be added to system path - [[enviroment variables.png | image link]]

<mark class="hltr-green">known commands:</mark>
```cmd
adb shell pm grant com.burockgames.timeclocker android.permission.SYSTEM_ALERT_WINDOW
```
